# Xダイジェスト｜株 × Claude Code

X（旧Twitter）から「株」と「Claude Code」の有力な情報を集めて、スマホで見やすく整理するアプリです。
ホーム画面に追加すると、アプリのように全画面で開けます（PWA）。

## できること
- **📈 株**：反響（いいね・保存・拡散）の大きい投資家の投稿と、株探・ブルームバーグ・ロイター・WSJ・JPX の報道/公式投稿
- **🤖 Claude Code**：最新リリース（@ClaudeCodeLog）、公式・開発チーム（Claude / Claude Developers / Anthropic / 開発者）、国内外の注目ポスト（英語は日本語訳つき）
- **話題のワード**：複数の人が触れている言葉を自動で抽出。押すと絞り込み
- **期間**（6時間 / 24時間 / 3日）と**並び順**（注目順 / 新着順）、キーワード絞り込み
- **ノイズ除去**：煽り・情報商材・プレゼント企画の言葉、いいね水増し（いいね ÷ 表示回数が大きすぎる）、話題から外れた投稿を除外。アカウント単位の「非表示」も可
- **NEW 表示**：前回見たあとに増えた投稿に印
- **AIまとめ（任意）**：Claude の APIキーを設定すると、「いま押さえるべき要点」を投稿番号つきで要約（キーは端末内にのみ保存）

## しくみ
- サーバーはありません。ページを開いた端末から [FxTwitter](https://github.com/FxEmbed/FxEmbed) の公開API（`api.fxtwitter.com`、非公式）を直接呼び、X の公開投稿を取得します。
- 取得した投稿・翻訳は端末の localStorage に保存します（注目ポストは約3日、公式・リリースは7日）。
- 英語の投稿は FxTwitter の翻訳（Grok）で日本語にしています。
- AI要約は Anthropic SDK（`@anthropic-ai/sdk`、esm.sh から読み込み）で Claude API を呼びます。既定モデルは Claude Opus 5.5。安全判定で断られたときは server-side fallback（`fallbacks: "default"`）で別モデルに切り替わります。

## 設定を変えるには
`config.js` を編集します。検索条件（X の検索演算子：`min_faves:` `lang:` `from:` など）、集めるアカウント、除外ワード、欄の構成を変えられます。

## 注意
- X 側や FxTwitter 側の変更で、取得できなくなることがあります。
- 投資判断はご自身で。X の投稿には誤り・煽り・なりすましが混ざります。
- 転載・AI加工を禁じていると明記しているアカウント（日経グループ、トレーダーズ・ウェブ）は集めていません。

## ファイル
- `index.html` … 画面とスタイル
- `app.js` … 取得・選別・表示・AI要約
- `config.js` … 集める対象と除外ルール
- `sw.js` / `manifest.webmanifest` / `icon-*.png` … PWA（`tools/make-icons.ps1` でアイコンを生成）
